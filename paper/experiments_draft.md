# Experimental section draft (MVP)

## Protocol

We evaluate whether repeating descendants of a shared premise changes a planner's belief without adding real evidence. The controlled SharedPremiseBench contains 5,000 procedurally generated tasks from five families (hidden state dependency, permission/tool availability, object-property uncertainty, resource constraint, and planning failure), three difficulty levels, train/dev/test splits, two counterfactual premise values, a provenance DAG, and up to 64 independent condition draws per action. Evaluation uses the held-out test split (78 tasks in the frozen scaling run). Pure duplication reuses the same sample ID and text; independent rollout uses fresh condition draws. Hidden state is unavailable to the planner and is used only for post-hoc reward, regret, and calibration labels.

The benchmark evaluator uses the same rollout bank for 11 methods: no imagination, flat rollout, independent trajectory, mean pooling, exact and semantic deduplication, source grouping, Bayesian mixing, a train-fit risk classifier, oracle provenance, and provenance-preserving aggregation. The semantic deduplication signature uses only planner-visible action, hypothesis value, and rounded predicted value, so it does not read hidden premise or source IDs. The flat method is a deliberately specified pseudo-likelihood mechanism with duplicate bias; this isolates the causal information error and is not presented as an empirical law of all language models. The formal invariance result also applies to any deterministic downstream statistic of the unchanged belief and normalized conditional summaries, including score, success-probability, and fixed risk-utility objectives.

The proposed implementation validates lineage fields, collapses repeated sample IDs inside action/premise/source partitions, averages retained conditional values, applies one weight per source group, and mixes those values with the evidence-only belief. Its grouping pass is linear in the rollout-bank size. The new provenance-recovery margin bound states when learned grouping preserves the oracle action as a function of total-variation recovery error and the action margin.

## Evaluation and uncertainty protocol

All controlled comparisons reuse the same frozen bank within each task and vary only the declared information condition. Benchmark intervals use 20,000 task-cluster bootstrap draws; interactive paired intervals resample episode or public-state units. DeepSeek request bodies, parsed JSON, token usage, and HTTP status are archived. The three-seed MVP uses independent task seeds because the provider exposes no API seed; byte-identical request controls are reported separately from method contrasts. Hidden simulator state is never sent to the model and is read only after action selection.

## Main result

Under pure duplication, flat root confidence rises from 0.510 at multiplicity 1 to 1.000 at multiplicity 64. Its action flip rate relative to multiplicity 1 reaches 0.564, and mean reward falls from 0.613 to 0.272. Provenance-preserving aggregation keeps confidence at 0.510, flip rate at zero, and reward at 0.613 across all multiplicities. Mean pooling, exact deduplication, source grouping, Bayesian mixing, and oracle provenance are also invariant in this stipulated bank; independent rollout is a separate information axis and is allowed to change conditional value estimates.

For uncertainty reporting, we resample the 78 held-out tasks with 20,000 deterministic task-cluster bootstrap draws. At duplication 8, flat confidence is 0.926 (95% CI 0.912--0.939), action-flip rate is 0.551 (0.436--0.667), and reward is 0.311 (-0.049--0.664); provenance confidence is 0.510 (0.462--0.555), with zero observed flips and reward 0.613 (0.398--0.806). These intervals describe task heterogeneity around the stipulated estimator. The corresponding CI scaling figure is `results_submission/report/controlled_curves_ci.png`.

Independent conditional samples form a separate information axis. Independent trajectory reward is 0.825 at budget 1 and 0.778 at budget 64, while the provenance-preserving duplicate baseline is 0.613 at budget 64. Paired reward contrasts are positive at every budget, but their point estimates are not monotone; the result is evidence for useful fresh value samples, not a claim that larger budgets always improve planning.

As a direct estimator check, we use the 64-draw conditional mean as an offline target for 624 held-out action/premise groups. Independent-sample MSE decreases from 0.052357 at n=1 to 0.000816 at n=64, while pure-copy MSE stays at 0.051736. The curve and exact values are in `results_submission/report/value_estimation_mse.csv` and `value_estimation_mse.png`.

A held-out qualitative case has a false shared premise. Flat confidence rises from 0.754 to 0.821 after only two copies and changes a +1.041 safe action into a -1.940 short-route action. Provenance remains at 0.754 and retains the safe action through 64 copies. The full table is in `results_submission/report/qualitative_examples.md`.

A fair ALFWorld algorithmic control now compares `flat_value` and `provenance_value` on identical candidate/conditional-bank requests. The batch covers three public-observation games, duplication 1/4, and 18 valid method-budget rows. At m=4, flat mean belief drift is 0.218 while provenance is exactly invariant; paired reward and success differences are zero. ## Learned provenance and ablations

A lexical pairwise extractor trained on train and threshold-tuned on dev recovers both premise edges and source-lineage edges with test F1 1.0 on the single-root lexical benchmark. A separate multi-root opaque-text stress composes 162 train, 43 dev, and 37 test composites, hides premise/source names, randomizes draw metadata, and retains 16 rollouts per root; the target-specific extractors fall to premise-edge F1 0.652 and source-edge F1 0.392. On the same stress, learned grouping reaches action correctness 0.257, reward 0.005, and regret 1.233, versus oracle correctness 1.0, reward 1.238, and regret 0. The latter is an edge/recovery stress diagnostic rather than a claim of robust semantic extraction. Margin-binned downstream rows report action correctness and cross-root merge rate by true action margin, making the Proposition 6 recovery bottleneck observable. Learned, generated-ID, and oracle grouping produce the same downstream test reward on the lexical toy bank; source-label noise and downstream reward/regret are reported at 0, .05, .1, .2, and .4 noise in `results_submission/provenance/noisy_downstream.csv` and `results_submission/provenance/test_source_downstream.csv`. Family/difficulty edge breakdown and the aggregate noise curve are generated in `results_submission/report/provenance_edge_breakdown.csv` and `results_submission/report/provenance_noise_curve.csv`. Mechanism ablations cover provenance removal, belief-separation removal, sample-identity removal, attention-only weighting, simple exact-text deduplication, random grouping, and oracle grouping.
The opaque stress also reports a 2,000-draw fixed-predictor permutation null: premise F1 0.652 equals its null mean 0.652, and source F1 0.392 is only modestly above null mean 0.354 (95% CI 0.350--0.358). We interpret this as an observability limit, formalized in Proposition 7, rather than as evidence that a stronger extractor can infer hidden lineage from no cue.
