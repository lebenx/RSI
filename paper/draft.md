# More imagination is not more evidence: provenance-preserving planning under shared premises

## Abstract

Language-model planners often generate many imagined continuations from one uncertain premise. A flat reader can treat the descendants as independent evidence and become increasingly confident without observing the world. We formalize this failure as shared-premise evidence duplication and separate belief over real premises from conditional value estimation. A provenance-preserving aggregator retains premise/source/sample lineage, normalizes repeated descendants, and mixes conditional values with the unchanged real-evidence belief. On a five-family benchmark with 5,000 generated tasks, flat confidence rises from 0.510 to 1.000 as exact copies increase from 1 to 64; action flips reach 0.564 and reward falls from 0.613 to 0.272. Provenance-preserving aggregation is invariant under copies while independent samples retain their variance-reduction benefit. DeepSeek and Qwen diagnostics show that the mechanism is not a universal default property of language models: effects depend on presentation and prompt. In 27 paired CUDA-Qwen ScienceWorld episodes, provenance-value gives positive reward contrasts in both task-family strata and zero duplication action flips across four fresh held-out expansions; the DeepSeek strata remain mixed. A subsequent bank audit finds that all 56 provenance episode rows follow candidate ID 0, with 751/768 decision rows returning constant conditional scores. The positive Qwen reward contrasts are therefore confounded by the readout and tie-breaking policy; a provenance-specific planning benefit is not established.

## 1. Introduction

Imagination is useful for planning because conditional rollouts estimate the value of actions that have not yet been executed. The same mechanism creates a subtle failure mode when many rollouts descend from one uncertain premise. If their shared parent is hidden, a flat reader may count repeated consequences as repeated evidence about the parent. The resulting confidence can change the selected action even though the agent has learned nothing new about the physical world.

We call this shared-premise duplication. The central design principle is simple: descendants can refine conditional values, but only real observations should update belief in the premise. Our contribution is a formal separation of these quantities, a provenance-preserving aggregation rule with a duplication-invariance guarantee, and an auditable benchmark that distinguishes exact copies, paraphrases, independent condition samples, and new observations. The guarantee is objective-agnostic for deterministic score, success, or risk readouts, while it does not guarantee that any one objective is a better planner. We also report negative real-model diagnostics rather than generalizing a stipulated analytical effect.

## 2. Problem formulation

Let `E` be real environment evidence and `H` a latent premise. The planner maintains `q(h)=P(H=h|E)` and conditional action values `Q(a,h)`. Its action score is `U(a)=sum_h q(h)Q(a,h)`. A descendant rollout contains a declared premise branch, action, simulated return, sample ID, and parent IDs. A pure duplicate reuses the sample ID and content; an independent rollout has a fresh random draw and ID. A duplicate is a presentation change, not a sensor observation.

The provenance-preserving estimator groups descendants by shared premise/source/sample lineage, computes within-group conditional means, and assigns group weights once. It then forms the explicit belief mixture. Flat aggregation instead treats repeated descendants as pseudo-likelihood terms. The formal propositions and proof sketches are in `paper/theory.md`.

The implementation validates lineage, removes repeated `sample_id` records within each `(action, premise, source)` partition, computes normalized conditional means, mixes them with the evidence-only belief, and applies a fixed action objective. Hashable lineage keys give linear time and memory in the number of rollout records. Proposition 6 bounds downstream score error from learned provenance recovery and gives a sufficient action-margin condition under which recovered grouping agrees with oracle grouping.

## 3. SharedPremiseBench

The benchmark contains 5,000 tasks from hidden-state dependency, permission/tool availability, object-property uncertainty, resource constraint, and planning-failure families. Each task has easy/medium/hard difficulty, a deterministic split, a hidden premise, two counterfactual hypothesis banks, a generated provenance DAG, and complete rollout lineage. Public task files omit hidden state and the graph. The frozen 1–64 scaling bank contains 500 tasks and 64 independent draws per action; the held-out test split has 78 tasks.

We evaluate 11 methods using the same bank and budget: no imagination, flat rollout, independent trajectory, mean pooling, exact deduplication, semantic deduplication, source grouping, Bayesian mixing, a train-fit risk classifier, oracle provenance, and provenance-preserving aggregation. Semantic deduplication uses only planner-visible action, hypothesis value, and rounded predicted value, without hidden premise or source IDs. The no-imagination and oracle variants are disclosed exceptions. The flat mechanism is intentionally stipulated as a pseudo-likelihood diagnostic; it is not a claim that every model implements it.

## 4. Evaluation protocol and uncertainty

All controlled comparisons reuse the same frozen rollout bank within a task and vary only the declared information condition. Held-out benchmark intervals use 20,000 task-cluster bootstrap draws; interactive paired intervals resample episode or public-state units. API experiments archive complete request bodies and responses. The minimal DeepSeek experiment has three independent task seeds rather than provider-controlled random seeds because the API does not expose a seed parameter; byte-identical request controls quantify residual provider stochasticity. ScienceWorld disallows gold paths and hidden-state access, and simulator outcomes are used only after action selection. These choices make the estimator and input boundary auditable, while they limit external-validity claims to the stated samples.

## 4. Results

Under pure duplication, flat confidence rises from 0.510 at multiplicity 1 to 1.000 at multiplicity 64. Its action flip rate relative to multiplicity 1 reaches 0.564, and reward falls to 0.272. Provenance-preserving confidence, action, and reward remain invariant at 0.510, the baseline action, and 0.613. Independent rollout changes value estimates without changing real-evidence belief. A held-out false-premise case changes flat's action from a +1.041 safe route to a -1.940 short route after two copies, while provenance remains unchanged.

Task-cluster bootstrap over the 78 held-out tasks gives, at duplication 8, flat confidence 0.926 (95% CI 0.912--0.939), action-flip rate 0.551 (0.436--0.667), and reward 0.311 (-0.049--0.664); provenance confidence is 0.510 (0.462--0.555), with zero flips and reward 0.613 (0.398--0.806). The intervals quantify task heterogeneity around the stipulated estimator; the full curves are in `results_submission/report/controlled_curves_ci.png`.

The independent-rollout condition is analyzed separately from duplication. Independent trajectory aggregation has reward 0.825 at budget 1 and 0.778 at budget 64, versus 0.613 for the provenance-preserving duplicate baseline at budget 64. Paired reward advantages remain positive across the budget axis, although the curve is noisy rather than monotone. This supports the value-estimation role of fresh conditional samples without claiming that more imagination always improves action selection.

Using the 64-draw conditional mean as an offline target, conditional-value MSE over 624 held-out action/premise groups falls from 0.052357 at one independent sample to 0.000816 at 64 samples. Pure copies remain at 0.051736 at every presentation budget. This directly verifies the variance-reduction mechanism in Proposition 4 while keeping belief unchanged.

Ablations show the same separation: removing provenance reproduces the confidence saturation; belief separation and sample identity controls remain invariant; attention-only and random grouping have different reward/regret profiles. The generated-ID and learned provenance extractors match the oracle on this lexical toy benchmark, while source-label noise produces measurable downstream degradation. Family/difficulty recovery breakdowns and the noise curve are archived in `results_submission/report/provenance_edge_breakdown.csv` and `results_submission/report/provenance_noise_curve.csv`. The benchmark's lexical labels make these recovery numbers an upper bound; the current opaque multi-root stress falls to premise F1 0.652 and source F1 0.392 with learned downstream reward 0.005 versus oracle 1.238. Its margin-binned table shows that cross-root merge error, rather than the aggregation rule, is the active downstream bottleneck.
The opaque stress now includes a fixed-predictor permutation null. Premise F1 0.652 is indistinguishable from its null 0.652, while source F1 0.392 is only modestly above a null mean 0.354 (95% interval 0.350--0.358). This is an observability boundary: provenance recovery needs an observable cue or external identifier, and aggregation cannot recover lineage that the input does not contain.

## 6. Limitations and falsification

The controlled flat curve isolates a specified estimator and therefore cannot establish that arbitrary LLMs count duplicates this way. Legacy fixed-snapshot rows are retained for auditability, but their trace-derived visible histories contain the post-action mutable history view and are excluded from causal claims. The clean serialized-input intervention reports the fixed-bank evidence. The lexical provenance recovery benchmark exposes condition words and source patterns; premise-edge and source-edge F1 are both 1.0 and are intentionally upper-bound diagnostics. In a separate multi-root opaque-text stress, target-specific extractors fall to premise F1 0.652 and source F1 0.392; learned grouping then reaches action correctness 0.257, reward 0.005, and regret 1.233 versus oracle correctness 1.0, reward 1.238, and regret 0, showing that semantic recovery remains an open component. The real-model sample remains exploratory, and ALFWorld now adds a 114-row public-observation comparison plus a separately labeled success-objective ablation rather than a broad planner-improvement claim. The CUDA-Qwen ScienceWorld table has 111 valid rows over 27 complete pairs, but remains task-family narrow despite the refreshed and contiguous extensions. A stronger paper would preregister larger multi-model runs and evaluate more diverse successful tasks. A null real-model effect is compatible with the theory because the theory constrains information and estimator design, not transformer internals.

## 7. Conclusion

More imagined continuations are useful when they are independent value samples. They are not additional evidence for a shared premise. Tracking provenance and preserving belief/value separation prevents exact duplication from changing confidence while retaining the computational benefit of independent rollouts. The artifacts establish the mechanism, its observability limit, and a reproducible evaluation protocol; the historical positive Qwen contrasts are confounded by rank-zero selection and do not yet establish a provenance-specific planning benefit.
